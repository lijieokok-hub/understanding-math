Unit 3: Extending row estimates from fixed to depth-varying inputs

This unit studies §§4.1–4.2 of D, pp.17–22, principally Lemmas 4.1–4.4. Linearizing the maximum in Unit 2 produced test functions that vary with scale. Here we examine an abstract operator-theoretic step used in the paper to control such variation.

The discussion ends at Lemma 4.4. It assumes the persistent-column structure, the refinement relations between two kinds of partitions, and the original joint Bessel estimate. Verifying these assumptions for the paper's particular projections, local modes, and smooth rows is a separate task.

1. Fixed-input and varying-input estimates

Suppose a family of bounded linear operators satisfies

∑ν∥Aνz∥2≤B2∥z∥2for every fixed z. \sum_\nu\|A_\nu z\|^2\le B^2\|z\|^2 \quad\text{for every fixed }z. ν∑​∥Aν​z∥2≤B2∥z∥2for every fixed z.

All rows here act on the same zzz. If row ν\nuν instead acts on FsνF_{s_\nu}Fsν​​, the estimate does not permit a separate replacement of zzz in each row. The paper controls total variation within deterministic input blocks and imposes a spatial structure on the adjoint rows.

There are two different indices in this unit: the index sss at which a function is sampled, and the depth of a spatial dyadic interval. They need not coincide. The rows are arranged in rounds nnn; every row in one round acts on the same FsnF_{s_n}Fsn​​, and the indices sns_nsn​ must be nondecreasing.

2.3 Nondecreasing sampling permits skipped and repeated indices

Later, only indices s1≤⋯≤sNs_1\le\cdots\le s_Ns1​≤⋯≤sN​ are sampled. Within an original block, each difference between consecutive sampled values is bounded by the sum of the differences across the intervening original edges. Nondecreasing order ensures that each original edge is used at most once; repeated indices contribute zero. Thus (V) remains valid along the sampled subsequence, with the original normalization WWW. Unsampled blocks contribute zero.

The same restriction applies to (D). Suppose intervals in the sampled list have edge overlap number mmm. Any original edge (j,j+1)(j,j+1)(j,j+1) corresponds to the unique cut in the list between indices at most jjj and indices greater than jjj. An interval crossing that original edge must cross this cut. Its overlap count is therefore still at most mmm.

3.4 Restriction to a subroot does not increase DDD

Take a dyadic subroot R′⊆RR'\subseteq RR′⊆R. Remove birth intervals disjoint from R′R'R′. If R′⊆JvR'\subseteq J_vR′⊆Jv​, regard R′R'R′ as the column's birth interval in the restricted system. 4.1 Two spatial partitions

5. Lemma 4.3: Grouping whole rows and proving the maximal estimate

5.1 Fix the test vectors before choosing common representatives

Source: D p.20, the first paragraph of the proof.

Retain only rounds p,…,qp,\ldots,qp,…,q, and relabel them 1,…,N1,\ldots,N1,…,N. Fix the test vector c=(cν)c=(c_\nu)c=(cν​) and threshold λ>0\lambda>0λ>0. 5.2 Number of groups and stopping threshold

Set

A single row may cover several observation intervals. It is therefore not permissible to decide when to stop separately at each point and then cut a row's output into arbitrary pieces. The two partitions prevent this problem.

5.3 Order of construction within each round

At the beginning of the first round, every support interval has group number 111 and current coefficient vector zero. The induction assumption is that, at the beginning of round nnn, the group number and current coefficient vector are constant on each Q∈πnQ\in\pi_nQ∈πn​, and the vector uses only labels in V(Q)\mathcal V(Q)V(Q).

First assign all rows supported on QQQ to that interval's current group. If its group number has already reached T+1T+1T+1, do not assign those rows.

Next, restrict attention to current group numbers at most TTT. On each corresponding finer observation interval K∈σnK\in\sigma_nK∈σn​, add the round's coefficients an(K)a_n(K)an​(K) to the current vector. If its ℓ2\ell^2ℓ2 norm exceeds τ\tauτ, record a threshold crossing, increase the group number by one, and reset the current vector to zero. Otherwise retain the vector and group number. After the TTT-th crossing, freeze the state at (T+1,0)(T+1,0)(T+1,0).

The new state is constant on each σn\sigma_nσn​-interval. Since πn+1\pi_{n+1}πn+1​ refines σn\sigma_nσn​, every support interval of the next round inherits a definite state. Old columns remain unchanged on restriction to descendants, and their labels remain available. Old and new coefficient vectors can therefore be added in the same space ℓ2(V)\ell^2(\mathcal V)ℓ2(V).

The induction preserves the whole-row assignment: each original row belongs to at most one group, with a single assignment over its entire support. Different stopping decisions on observation intervals never split a previously assigned row. All states are determined by finitely many intervals and operations on constant vectors, so the crossing sets are measurable.

7. Applying the lemma: what still has to be checked

The paper permits the constructed finite rows, partitions, and column family to depend on the given function sequence (Fs)(F_s)(Fs​). Once constructed, however, these objects must be fixed, and (B) must be verified for every test input zzz. An estimate only for the original FsF_sFs​ would not support the test-dependent grouping in Lemma 4.3 or the duality argument in Lemma 4.4.

Each application must check at least the following: whole-row supports are preserved; the adjoints have constant-coefficient representations on observation cells using the same persistent column family; the next support partition refines the current observation partition; the joint Bessel bound holds for arbitrary inputs; and every row in a round samples the same index, with those indices nondecreasing across rounds.

No mixing is used in this unit, and the local quadrilinear Theorem 3.2 has not been deduced. What has been proved is one varying-input row estimate used in the paper. Applications to projection increments, smooth mean-zero rows, and subsequent local modes still require the stated structure to be verified in each case.
