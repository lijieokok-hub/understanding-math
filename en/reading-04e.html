Unit 4, continued: Maximizing auxiliary positions and stabilizing conditional expectations

This part studies B §§6.1–6.3, pp.18–21. Pointwise failure has already supplied fixed selectors, a common ultrafilter, and a nonzero correlation. Preservation of the three auxiliary groups remains conditional on the higher-order mixing and relative structure results stated earlier in Unit 4.

We choose a nonzero correlation with as many auxiliary positions as possible, then extend the system so that specified conditional expectations no longer change under further extensions. The final construction regroups the auxiliary variables; the next part computes row and column conditional laws in that system.

3. Three auxiliary positions would yield too many orthogonal functions

Source: the remainder of B Proposition 6.1, pp.18–19.

3.1 Repeatedly retaining one coordinate at speed one

3.2 Every line has the same selected law

The ordered four states on every coordinate line have law λY\lambda_YλY​. This follows by induction from the construction, without assuming symmetry between rows and columns.

If the varying coordinate is the newly added one and the others are fixed at bbb, successive old-coordinate projections define a speed-one factor. Compatibility of the selected law with projections gives λY\lambda_YλY​ as the law of this new line.

If an old coordinate varies while the new coordinate is fixed at bbb, the new law's marginal at coordinate bbb is the preceding array measure. The induction hypothesis then identifies the line law.

Thus every line has the required distribution, without interchanging coordinate axes.

5. The increasing-energy construction

5.1 Monotonicity of the energy

Fix a function fff on a selected-law space and a type lll. Define

EY(f,l)=∥EλY(f∣Dl(Y))∥22. \mathcal E_Y(f,l) =\|\mathbb E_{\lambda_Y}(f\mid\mathcal D_l(Y))\|_2^2. EY​(f,l)=∥EλY​​(f∣Dl​(Y))∥22​.

5.2 Countably many tests suffice

Starting from Y0Y_0Y0​, construct an extension chain Y0←Y1←⋯Y_0\leftarrow Y_1\leftarrow\cdotsY0​←Y1​←⋯. Each space L2(λYn)L^2(\lambda_{Y_n})L2(λYn​​) is separable. At every new stage, choose a countable dense set of functions and retain all previously chosen functions by pullback.

Use a countable interleaving so that every introduced function and every type lll is revisited infinitely often with errors tending to zero. For example, enumerate quadruples consisting of introduction stage, function index, type, and accuracy, processing each only after its stage exists.

At a step treating (f,l)(f,l)(f,l), choose a standard extension whose energy is within the prescribed error εn\varepsilon_nεn​ of the supremum over all standard extensions. The supremum is finite, and the identity extension makes the collection nonempty. The definition of supremum therefore permits this choice.

This is an existence argument. It does not assume that any extension attains the supremum exactly.

5.3 The inverse limit retains the selected tests

Take the countable inverse limit YYY using the full-countable-product construction from Part I. It accommodates fixed-time factor relations modulo null sets without requiring a compatibility set invariant pointwise at all real times.

The selected laws are compatible with the stage projections, and the union of the pulled-back stage L2L^2L2 spaces is dense in L2(λY)L^2(\lambda_Y)L2(λY​). The retained dense tests are consequently dense in the limit space.
