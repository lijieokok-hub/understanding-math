Unit 3, continued: why frozen mode rows cost only the main-column bound

This part develops D §6.3 and Lemma 6.3, pp.47–49. The mode family may be much larger than the main column family. Before inserting functions from different frozen depths, the key is to assemble all mode rows into an ordinary Bessel operator. Composition with main projections then places the final adjoint range on the whole main endpoint interval.

We use the first-match expansion in H Lemma 8.1, the ordinary joint Bessel bound for the specified mode rows, separation of usable main endpoint spaces, and H Compression. Their respective roles are stated below. Deriving the mode-row Bessel bound from the frequency-graph construction still requires D §6.4 and the corresponding geometric arguments in H.

8. Why the final constant is DmD_{\mathrm m}Dm​ rather than D∗D_*D∗​

The mode projections PeP_ePe​ and map RG\mathcal R_GRG​ have already been handled in constructing the ordinary joint Bessel operator. Their relevant hypotheses enter through (Mode-Bessel) and the uniform map norm.

For the varying-function row estimate, the relevant column representation is that of the final range of Te∗T_e^*Te∗​. This range is determined by the input-side underlying main projection QUeτQ^\tau_{U_e}QUe​τ​, so the column constant is DmD_{\mathrm m}Dm​.

Ignoring the composition order and using D∗D_*D∗​ merely because a mode projection appears in the middle would introduce extra losses that may contain a fixed power of PPP. Conversely, if the underlying projection were removed, the final adjoint could no longer be asserted to have main-column range without a new check. This conclusion applies here only to the specified basic BBB components.

The joint Bessel hypothesis for the mode rows must still be checked for the mode families actually selected later. Stating it as a hypothesis does not imply that arbitrarily large mode families satisfy the same bound G0G_0G0​.

9. The frozen depth determines use and observation

For a row from analysis block [b,b+K)[b,b+K)[b,b+K), its main endpoint interval has depth ub=b−4Ku_b=b-4Kub​=b−4K. Thus

s(Ue)=ub s(U_e)=u_b s(Ue​)=ub​

is both the function index and the observation depth in the final varying-function row estimate. Neither the finer mode-output interval JeJ_eJe​ nor the later depth where the form is actually used changes this assignment.

The normalized sequence is already controlled on the whole depth-ubu_bub​ interval. No fine-interval norm needs to be enlarged back to an ancestor interval. Freezing 4K4K4K levels earlier therefore introduces no factor 24K2^{4K}24K here. The change in the actual output from depth ubu_bub​ to the current depth is controlled separately by the preceding depth-variation estimate.
