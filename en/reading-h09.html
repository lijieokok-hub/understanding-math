Why a column catalog still terminates with changing projection histories

This chapter closely reads Lemma 6.7 in H §6.4, pages 47–49, and fully develops the estimate it needs from Lemma 3.3, pages 8–9. The fixed source is An L3L^3L3 bound for the trilinear Hilbert transform, October 5, 2026 version.

The same-tag test in the previous chapter shows that whenever a four-linear smallness test fails, a new template has a large moment against the residual. This chapter proves that only finitely many such insertions can occur, and that the logarithm of their total number is still bounded by a fixed power of the original parameter. The difficulty is that the states being tested also change: one insertion can change several projections and hence all subsequent tested states.

The proof of Lemma 6.7 in the source cites the binary-prefix argument in Lemma 3.4. Here we directly prove and use the row form of Lemma 3.3, with insertion times as indices within one fixed cell. We do not first need the full compression conclusion of Lemma 3.4 for arbitrary spatial depth.

This distinction cannot be omitted. In CT\mathbb C^TCT, let QtQ_tQt​ project onto the first ttt coordinates and freely choose Xt−1=etX_{t-1}=e_tXt−1​=et​. Every state then has norm 111, but

Bν:X⟶Yν,∑ν∥Bνh∥2≤∥h∥2(h∈X).(Row contraction condition) B_\nu:\mathscr X\longrightarrow\mathscr Y_\nu,\quad \sum_\nu\|B_\nu h\|^2\le\|h\|^2 \quad(h\in\mathscr X). \tag{Row contraction condition} Bν​:X⟶Yν​,ν∑​∥Bν​h∥2≤∥h∥2(h∈X).(Row contraction condition)

(∑ν∥BνTt(ν)m⋯Tt(ν)1g∥2)1/2≤(2LT)m∥g∥.(Row bound with complements) \left( \sum_\nu\|B_\nu T_{t(\nu)}^m\cdots T_{t(\nu)}^1g\|^2 \right)^{1/2} \le(2L_T)^m\|g\|. \tag{Row bound with complements} (ν∑​∥Bν​Tt(ν)m​⋯Tt(ν)1​g∥2)1/2≤(2LT​)m∥g∥.(Row bound with complements)

This bound requires no commutativity between different layers.

Return to the fixed cell III and fix one target mask and one history name. Take the row operators and prefix times to be

Bt=ΔQt,t(ν)=t−1. B_t=\Delta Q_t,\quad t(\nu)=t-1. Bt​=ΔQt​,t(ν)=t−1.

Since the target increments have mutually orthogonal ranges,

∑t=1T∥Bth∥2,I2≤∥h∥2,I2. \sum_{t=1}^T\|B_t h\|_{2,I}^2\le\|h\|_{2,I}^2. t=1∑T​∥Bt​h∥2,I2​≤∥h∥2,I2​.

It follows that

∑t=1T∥(ΔQt)Tt−1m⋯Tt−11g∥2,I2≤(2LT)2m∥g∥2,I2.(Total energy for a changing history) \sum_{t=1}^T \|(\Delta Q_t)T_{t-1}^m\cdots T_{t-1}^1g\|_{2,I}^2 \le(2L_T)^{2m}\|g\|_{2,I}^2. \tag{Total energy for a changing history} t=1∑T​∥(ΔQt​)Tt−1m​⋯Tt−11​g∥2,I2​≤(2LT​)2m∥g∥2,I2​.(Total energy for a changing history)

Restricting the sum to the times actually charged to this name can only decrease the left side.

Insertion steps at all ranks are counted together. Insertions at other ranks can change both the history and the target projection. These changes are already included in the corresponding increasing projection families. If a step does not change the target space, its row increment is zero. We need not first assume that the catalogs at other ranks have stopped changing.

The choice of a failed test may depend on the input and earlier insertions. To apply the row estimate, first fix the finite trial sequence actually obtained and all its projection families, then use the deterministic inequality valid for every such family. No probabilistic independence is required between the projections, row operators, and base vector.

8. From one cell to a path

A spatial path has at most MMM active cells. Insertions take place separately in each cell, and child cells inherit columns already inserted by their ancestors. The same private label inserted by an ancestor is counted only once along the path.

The fixed-data budget lets us choose a fixed integer a≥2a\ge2a≥2 such that, for sufficiently large kkk,

The catalog construction already assigns a name to each specific pad choice. For every term, the form test satisfies the same bound in source equation 13. 13. Parameter order for the catalog budget and graph threshold

The graph edge threshold HedH_{\mathrm{ed}}Hed​ determines which tags are adjacent and can change the specific masks. The insertion count above, however, uses only an upper bound on the number of names, not numerical distances. The complexity of each new column comes from Lemma 6.6 and is fixed from the outset; it does not grow with insertion rank.

We may therefore make the choices in this order:

  1. Fix the budgets for basic template complexity, colors, and history length, and then fix all nrn_rnr​ as in Section 9;
  2. Using these path counts, private weights, and coefficient budgets, choose τ2\tau_2τ2​ sufficiently small for Lemma 6.5 and the later mismatch errors;
  3. Finally choose HedH_{\mathrm{ed}}Hed​ by Lemma 6.1 so that correlations between nonadjacent tags are below the required τ2\tau_2τ2​.

Only for the graph finally chosen do we fix a suitable color realization and the actual masks, and then carry out the catalog construction. The counting estimates are uniform in these particular values. The same random color array is not required to work simultaneously for every possible HedH_{\mathrm{ed}}Hed​.

If template complexity increased with every insertion, H0H_0H0​ in the first step would depend on the as-yet-unknown number of insertions, and this parameter order would fail. The previous chapter's distinction between a fixed amplitude family and arbitrary external modulation is exactly the input needed to avoid that problem.

14. What this chapter closes, and its limits

Under fixed original graph data, finitely many named histories, fixed base vectors, and an active-cell path budget, the main catalog terminates after finitely many steps, as does the subsequent helper catalog based on fixed whole side states. All required pure-source residual tests hold. The logarithm of the path column count is bounded by a fixed power of kkk, and each column's nonlinear complexity does not increase with insertions.

The proof develops three steps: new private coordinates turn a large physical moment into an orthogonal increment; the binary-prefix row bound handles changing projection histories of the same fixed base vector; and one simultaneous choice of all rank budgets rules out the first path-budget violation. Changing states are not treated as fixed vectors, and the energy budget is not paid anew for each triggering source.

The retained source inputs include the active-cell path count from Proposition 5.8, which finitely many named histories are required by later localization and transfer, and the construction and number of whole helper base vectors in Section 7. We have not proved the full Lemma 3.4 compression for arbitrary spatial depth, nor upgraded this local catalog closure to the full main theorem of H.

The actual later histories are now listed individually in H12, Section 6, and the history appendix. H12 uses them to develop current-group localization and both far-band directions. Construction and counting of complete side bases, linear side energy, and global near-band estimates remain later inputs. This companion argument does not change the conditional catalog-termination conclusion of the present chapter.
