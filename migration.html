迁移已保存的进度

阅读正文、检索、游戏、视频与专题报告在此 GitHub Pages 站点运行。支持批注的阅读页现已在本站直接提供建议和已公开讨论。

把游戏进度带过来

  1. 在原来玩游戏的浏览器中打开原站游戏。
  2. 进入选关页，展开“保存这趟旅程”，点击“导出进度”，保存 JSON 文件。
  3. 打开本站游戏，在同一菜单点击“导入进度”，选择刚保存的文件。

导入会保留较高的关卡记录。文件在你的浏览器中处理，本页不会上传或自动传送记录；建议保留这份备份。不同浏览器和不同网站地址各自保存进度，登录账号不会自动同步。

阅读位置与设置

原站阅读位置和主题设置不会自动迁到新地址。可以保留原来的页面，在本站找到对应章节和小节后继续阅读。新的位置与设置保存在当前浏览器本地。

提交建议与查看讨论

在本站阅读页选择一段文字或公式，即可添加建议。服务器确认保存后，建议仅作者可见、等待审核；文章下方只显示已审核公开的讨论与回复。

保存失败时，请保留当前页面中的草稿并重试。关闭或刷新页面会清除未保存的草稿。
