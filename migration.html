迁移进度与提交建议

阅读正文、检索、游戏、视频与专题报告在此 GitHub Pages 站点运行。建议和讨论暂时保留在原站。

把游戏进度带过来

  1. 在原来玩游戏的浏览器中打开原站游戏。
  2. 进入选关页，展开“保存这趟旅程”，点击“导出进度”，保存 JSON 文件。
  3. 打开本站游戏，在同一菜单点击“导入进度”，选择刚保存的文件。

导入会保留较高的关卡记录。文件在你的浏览器中处理，本页不会上传或自动传送记录；建议保留这份备份。不同浏览器和不同网站地址各自保存进度，登录账号不会自动同步。

阅读位置与设置

原站阅读位置和主题设置不会自动迁到新地址。可以保留原来的页面，在本站找到对应章节和小节后继续阅读。新的位置与设置保存在当前浏览器本地。

提交建议与查看讨论

支持建议功能的阅读页会链接到原站对应文章。选中引文后，可打开同语种的原文小节，再在那里选取段落并提交建议。链接只包含公开文章地址与小节，不包含选中文字或草稿。本静态站点不会显示虚假的保存成功，也不会复制私有讨论。

在原站提交的建议仍遵循私有、待审核流程，由站主在那里核实和回复。
